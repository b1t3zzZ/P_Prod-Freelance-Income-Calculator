📋 Подробный To-Do лист для разработки (на 18 часов)

🛠 Этап 1: Подготовка и структура (120 минут / 2 часа)

[ ] Инициализировать проект через Vite + Vue 3 (npm create vite@latest).



[ ] Установить и настроить CSS-фреймворк для быстрого дизайна (например, Tailwind CSS или Bootstrap/Bulma).



[ ] Продумать структуру компонентов во Vue:



App.vue (главный контейнер)



IncomeForm.vue (форма ввода данных: ставки, часы, налоги)



SummaryCard.vue (блок с итоговыми расчетами)



HistoryList.vue (список сохраненных расчетов)



💻 Этап 2: Создание формы и логики расчета (480 минут / 8 часов)

[ ] Сверстать поля ввода для основных параметров:



Часовая ставка или фиксированная плата за проект.



Количество отработанных часов / дней.



Процент налога (например, самозанятость 4-6% или подоходный налог).



Комиссия платформы (если работа через фриланс-биржи, например, 10–20%).



[ ] Написать реактивную логику с помощью ref / reactive и вычисляемых свойств (computed), чтобы расчет происходил мгновенно при изменении любого поля.



[ ] Реализовать формулы:



Валовый доход (Gross Income) = Ставка × Часы.



Сумма налога и комиссий.



Чистый доход на руки (Net Income) = Валовый доход минус налоги и комиссии.

[ ] Добавить красивое отображение итоговых сумм (крупные цифры, иконки валют).



[ ] Реализовать сохранение истории расчетов или текущих настроек в браузере через localStorage, чтобы данные не пропадали при перезагрузке страницы.



[ ] Добавить кнопку «Сбросить» и валидацию полей (чтобы нельзя было ввести отрицательные числа или буквы вместо цифр).



🚀 Этап 4: Полировка, тестирование и деплой (240 минут / 4 часа)

[ ] Проверить верстку на мобильных устройствах (адаптивность через медиа-запросы или классы Tailwind).



[ ] Убедиться в отсутствии багов в расчетах при крайних значениях (нули, пустые поля).
